# Notas de complejidad para Repaso OOP, debugging y cambios

- Pregunta siempre si la entrada ya viene ordenada.
- Distingue entre espacio de salida y espacio auxiliar.
- Si usas hashing, menciona que el lookup es promedio O(1).
- Si ordenas, el costo dominante suele ser O(n log n).

## Preguntas de repaso
- Cual es la operacion dominante.
- Que memoria extra agregaste y por que.
- Como cambiaria la complejidad con una entrada diez veces mayor.
