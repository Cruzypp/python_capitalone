# Interview Cheatsheet

1. Restate the problem.
2. Ask clarifying questions.
3. Discuss examples.
4. Propose an approach.
5. Explain data structures.
6. Implement.
7. Test.
8. Analyze complexity.
9. Discuss alternatives.

Useful phrases in English:
- I want to restate the problem to confirm my understanding.
- Before coding, I would like to clarify the constraints.
- I will start with a straightforward solution and then optimize it.
- I am using a dictionary because it gives average O(1) lookup.
- Let me test the edge cases before I finalize the answer.
- The time complexity is O(n), and the space complexity is O(n).
- An alternative would be a brute-force approach, but it would be slower.
